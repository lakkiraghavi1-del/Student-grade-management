Student Grade Manager
A simple Python-based Student Grade Manager that allows users to add, view, search, and delete student records while automatically calculating their average marks and corresponding grades.

This project is designed as a beginner-friendly console application demonstrating fundamental Python concepts such as functions, dictionaries, loops, conditional statements, exception handling, user input, and basic data management.

Features
Add a new student with marks for 5 subjects

Validate marks to ensure they are between 0 and 100

Handle invalid numerical input gracefully

Automatically calculate the student's average marks

Automatically assign a grade based on the average

View all registered students

Search for a student by name

Delete a student record

Prevent duplicate student records

Interactive command-line menu

Grade Criteria
The application assigns grades according to the following grading scale:

Average Marks	Grade
90 – 100	A+
80 – 89.99	A
70 – 79.99	B
60 – 69.99	C
50 – 59.99	D
Below 50	F
Technologies Used
Python 3

Python built-in functions and data structures

No external libraries or dependencies are required
